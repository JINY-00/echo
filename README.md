# Echo

面向手机浏览器的免费英语学习规划与训练工具。无需账号，学习数据保存在用户自己的设备中。

## 已包含的功能

- 日常交流、旅行英语、职场英语 3 条路线
- 自学打卡模式：自己选材料，应用安排每日行动、时间和验收标准
- 统一学习首页：进度数据、自学打卡和专项训练两个固定入口
- 每 5 个学习日提交一次周期成果，自动检查材料完整度并生成报告
- 材料标题、作者、链接、笔记和未解决问题可追溯保存
- 12 周作为一个训练周期，结束后自动进入下一周期，可长期使用
- 周计划按照用户选择的真实开始日期显示，不强制从周一开始
- 每条路线 12 周、60 个正式学习日
- A1 / A2 / B1 三档实际难度
- 24 题分级测试：词汇、语法、听力、阅读
- 每日精听、跟读、词汇、开口与客观小测
- 10 分钟保底模式、错题收集、间隔复习
- 12 次周检验：客观判分 + 录音自评
- 连续学习、进度、日历足迹和里程碑
- 本机录音、导出/导入备份、日历提醒
- PWA 安装到主屏幕及离线缓存

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npm test
npm run build
```

## 发布

推送到 GitHub 的 `main` 分支后，在仓库 **Settings → Pages** 中选择 **GitHub Actions**。工作流会自动测试、构建并发布。

建议使用公开仓库，这样 GitHub Free 可直接使用 Pages。仓库内不应放密码、个人录音或学习备份。

## 数据与隐私

- 设置、计划、打卡、答题记录：浏览器 `localStorage`
- 周测录音：浏览器 `IndexedDB`
- 云端：不收集、不存储个人学习数据
- 跨设备：使用“导出备份 / 导入备份”

## 判分说明

- 选择、填空、听力理解：按预设答案客观判分
- 词汇：按“记住 / 模糊”安排间隔复习
- 开口：提供录音、范读和可核对的自评清单
- 本项目不冒充 AI 给口音或自由表达打“精准分数”
