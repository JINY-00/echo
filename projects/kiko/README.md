# Kiko

Small moments, gently in rhythm.

Kiko 是一个安静的个人节奏空间，把想做的事、走过的进度和偶尔的停歇，轻轻放进每一天。

## 功能

- 随日期呈现当天节奏
- 轻触记录、今日进度与连续完成天数
- 一周视图与弹性时间安排
- 12 周阶段目标
- 每日随记与阶段回顾
- 可添加到 iPhone 或安卓主屏幕
- 打卡数据保存在本机浏览器，不需要账号

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

发布前检查：

```bash
npm test
```

## 数据说明

所有打卡、笔记和总结都只保存在当前浏览器的本地存储中。更换设备、使用另一个浏览器或清除浏览器数据后，记录不会自动同步。
